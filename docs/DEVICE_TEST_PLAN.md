# Android 安装与验收（未执行项不得标通过）

1. 安装 RN 测试 APK（debug 签名与旧发行版不同；已有旧版时请先导出重要结果，勿直接清除数据）。
2. 记录设备/Android/WebView（旧入口使用时）/屏幕刷新率/ABI，录制 gfxinfo 或 Perfetto FrameTimeline。
3. PNG/JPEG/PDF/无扩展名/伪扩展名导入：核对原生探测能力与工具列表。
4. 每个 p=.1/.3/.5/.7/.9 反拖回起点，提前松手不提交；p>=.92 且球心在中央有效区域松手只生成一个 task ID；p>=.92 但明显侧偏或上方过冲时必须回弹。取消捕获/多指/快速连续中断。
5. 原生图片/音频、PDF渲染、系统选择器/保存/分享，分别完整端到端。
6. 切主题、旋转、切后台：任务仍与快照一致；少动态仍可操作。
7. 系统文档选择器前台时杀进程，返回输入/保存URI：Activity DocumentInbox 应重放一次；待导出ZIP不被启动清理。
8. 错误密码PDF/大ZIP取消/磁盘空间不足/输出损坏：无假成功、临时目录按策略清理。
9. Skia实际BackdropFilter折射/色散/焦散，浅深主题对照原仓库关键帧；报告实际差异。
10. 60/90/120 FPS 必须根据设备可观测帧时间统计，不以桌面CanvasKit或理论值替代。
