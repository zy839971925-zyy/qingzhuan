# 开发说明

项目根目录运行 `python3 setup_tools.py` 与 `python3 build.py` 可构建预览 APK；需要 Android SDK Platform 36、Build Tools 36.0.0 和 JDK 17 或更高版本（建议 JDK 21）。若需签名，开发密钥应保存在源码目录之外。
