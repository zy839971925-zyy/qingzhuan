# 1.3.0 黑白首页与球内反馈

用户授权自行决定视觉并直接交付APK，不再选择方案。选定近白纸面/近黑深色，移除标语、英文品牌大标题、装饰卡片。首页仅虚线上传区和低强调更多入口；实际文件类型图标、格式错峰/模糊/翻转、选择后半圆罩升起。Lucide矢量在Skia画布内绘制，因此可参与真实背景折射，许可随包保留。

保留原GLASS/LENS源码与原手势物理；仅玻璃表面Paint施加低饱和ColorMatrix，折射与RGB边缘色散仍走原始透镜Shader。自动深浅色覆盖主页、面板、ReactActivity系统栏和原生启动背景。

App按任务ID锁存视觉反馈。真实转换立刻执行和落盘，视觉完成独立等待UI帧：至少1200ms圆环过程，随后描绘绿勾并停留420ms，再松开视觉busy，原路径返回并恢复结果。最快任务也不会跳帧直接显示结果；未知进度以非线性视觉填充且不显示假的数字，真实成功前不走满；有进度时向真实值平滑推进。时钟指针持续顺时针扫动。后台暂停不积累可见动画时间，失败/取消直接退出成功反馈。旧任务的动画回调不能结束新任务。

验证：TypeScript和21项前端测试通过；包括真实App组件在同步完成/同步失败/旧回调场景的行为，实际Worklets编译闭包回归，以及反馈纯状态步进。25项会话与9项诊断存储测试通过；原Shader14帧桌面光学测试通过。未启动模拟器，Android页面视觉、手机实际转换、帧率与触摸延迟需设备复验；不以静态生图当作运行截图。
