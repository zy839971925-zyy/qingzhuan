外观

真实能力，有边界

图片转 JPG / PNG / WebP、图片成 PDF、PDF 合并 / 拆页 / 页面图片 / 文字提取、文档文字转换、CSV / TSV / JSON / XLSX、压缩 / 解压、音频提取和文件校验。

界面按文件内容及手机解码能力提供选项。文档仅重建文字，不保留原排版；表格不计算公式；GIF 仅首帧。不含 OCR、MP3 编码、视频转码或 RAR5 解压。

最多 20 份文件，单份 512 MiB，输入合计 1 GiB。解压上限 2000 项 / 1 GiB，PDF 上限 1000 页。应用内结果超过 2 GiB 后须先导出清理。

任务由本机处理。系统终止进程后不会自动续跑；会保留输入，提示重新转换。

离线与开源

无网络权限。转换使用随包的原生引擎；动效使用本地 GSAP 及原创 WebGL Shader。玻璃折射使用显式合成背景与文字纹理，兼容模式使用轻量材质。
